Every InCloseMail build, newest first. The latest is build 1 of 6 November 2026. InCloseMail offers each new build when it starts, or choose Help → Check for Updates.

Running a build from 27 October earlier than build 17? It can’t install updates itself: download the latest installer and run it once.

6 November 2026

Build 1 version 26.11.601

Fixed

  • Saving files with unusual names. An attachment named like a Windows device (aux.pdf, con.txt, COM1), a message with such a subject, or an attachment name over 255 characters couldn't be saved. Now they save, with a _ added in front or the name shortened.
  • Save Folder As and Export to .mbox, run twice to the same place, make a new folder ("Inbox (2)") instead of adding to the first one.
  • Internet calendars: a feed with one malformed event no longer fails as a whole (or keeps InCloseMail's saved copy of it from loading at start); that event is skipped and the rest shown.
  • Smaller fixes found by testing InCloseMail with damaged and unusual input.

5 November 2026

Build 14 version 26.11.514

New

  • Script rules. Home → Rules → Script Rules runs a script of yours when matching mail arrives, as classic Outlook's "run a script" rule did, with a PowerShell script, batch file or program instead of VBA. Match on the mailbox, the sender, the subject and attachments; Run Now tries a rule on the selected message. The script gets the message's details as a JSON file and the message as an .eml file; nothing from the message is put on its command line. Rules run while InCloseMail is open and are kept on each PC.
  • For IT: a "Don't run script rules" policy (DisableScriptRules) turns them off.

Build 13 version 26.11.513

New

  • Export to .mbox. Right-click a folder → Export to .mbox... to save its messages in one .mbox file, which Thunderbird, Apple Mail and archive tools open. If the folder has subfolders, you're asked whether to include them; each then becomes its own .mbox file, in folders that mirror yours. Right-click the mailbox itself to export everything. It works on a read-only mailbox too.

Build 12 version 26.11.512

New

  • For IT: a policy to keep settings sync always on or always off. "Keep users' settings the same on every PC" in InCloseMail's Group Policy and Intune templates (registry value SyncSettings, 1 or 0). Switched off, InCloseMail neither reads nor writes the hidden settings folder in the mailbox; either way, the choice in File → Options → Advanced is greyed out.

Build 11 version 26.11.511

Fixed

  • Settings changed on two PCs before they sync are combined. If you added a Safe Sender (or a Quick Step, say) on each of two PCs within a few minutes, one could replace the other. Now both are kept; for single choices, the newer one wins.

Changed

  • File → Options → Advanced says when a PC isn't sharing its settings. A PC where changes to your mailbox are off (a new PC starts that way) takes your settings from your other PCs but doesn't share its own; turn on Allow changes to my mailbox on the Mail page to share them.

Build 10 version 26.11.510

New

  • Your settings follow you to your other PCs. Your options and views, Safe Senders, Quick Steps, Favorites, contact groups, the shared mailboxes and calendars you added, signatures, templates and Quick Parts are kept in your own mailbox, in a folder Outlook doesn't show, and InCloseMail on your other PCs picks them up within 15 minutes. Change one thing on each PC and both changes are kept. Window sizes, sign-ins and the settings for the copy of your mail on each PC stay where they are. Nothing is stored anywhere but your mailbox. To turn it off on a PC: File → Options → Advanced → Keep my settings the same on every PC.

Build 9 version 26.11.509

Fixed

Now the account is set aside at once: it leaves the folder pane, its mail stays on your PC, the status bar says it needs you to sign in again, and File → Account lists it with Sign In Again and Remove.

Build 7 version 26.11.507

Build 5 version 26.11.405

New: more of Outlook's keyboard shortcuts

  • Anywhere: Ctrl+O opens the selected item. Alt+Left (or Alt+B) goes back to the view you were in, Alt+Right forward again. F11 goes to Search People. Ctrl+Alt+S opens the Send/Receive settings. Ctrl+Alt+K, Ctrl+Alt+Z and Ctrl+Alt+A search the current folder, its subfolders, or the whole mailbox.
  • Mail: Ctrl+Shift+D ignores a conversation, Ctrl+Insert copies, Shift+F4 finds the next match in a message.
  • Calendar: Alt+1 to Alt+0 show one to ten days. Alt+Minus shows the week, Alt+Equal the month. Ctrl+Left and Ctrl+Right go a day back or forward, Alt+Home and Alt+End to the start or end of the week, Ctrl+Comma and Ctrl+Period to the previous or next appointment.
  • Reminders: Alt+S Snooze, Alt+D Dismiss, Alt+O Open Item, Alt+A Dismiss All.
  • Writing a message: Ctrl+Space clears formatting, Ctrl+Q removes paragraph formatting, Ctrl+Shift+J justifies, Ctrl+Shift+N applies the Normal style, Shift+F3 changes case, Ctrl+Shift+H deletes the next word, F4 and Shift+F4 find.

The full list is on the keyboard help page.

Fixed

  • Ctrl+R, Ctrl+Shift+R and Ctrl+F act on what you're looking at. In the calendar they replied to or forwarded the message left selected in Mail. Now they reply to a meeting's organizer, reply to everyone invited, or forward the meeting; in People, Ctrl+F forwards the contact as a business card.

The checks now carry on during the download.
  • Install now installs the newest version. If a newer version came out after InCloseMail offered one, Install now installed the older one. It now checks again first.
