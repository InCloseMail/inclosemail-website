InCloseMail’s public beta starts here. As new builds come out, what changed in each is listed on this page, newest first. InCloseMail offers each new build when it starts; you can also choose Help → Check for Updates.

November 10, 2026

InCloseMail 26.11.1004

Rules

  • Run one rule any time. In Rules and Alerts, select a rule and click Run Selected Rule to run just that rule on the messages already in the folder chosen beside Run Rules Now, even if the rule is turned off. Before, a single rule could only be run as it was saved.

Updates

  • What’s new from File → Account. When an update is available, What’s New beside Install now shows what’s in it. When you’re up to date, What’s new in InCloseMail opens the release history.

InCloseMail 26.11.1003

Dialogs

  • Use the keyboard in every dialog. In a question like "Move 2 Folders to Spam?", Left and Right move between the buttons and Space presses one. In a dialog with options and OK/Cancel, Up and Down move between the options, and Left and Right move to OK and Cancel.
  • Only the button you’re on is outlined. Moving from Yes to No moves the blue outline with you; Enter presses the outlined button.
  • Buttons match. OK and Cancel (and the other buttons in a row) are now the same size and line up in every dialog.
  • Long choices wrap. An option too long for the dialog (such as keeping a deleted folder’s rules) wraps onto more lines instead of being cut off.

Select Names

  • Readable in Dark Mode. The highlighted name in Select Names (and in Mailbox Cleanup and Manage All Views) is no longer white on light blue.
  • Pick a name and click OK. With nothing on the To line, OK now uses the names you highlighted, so a rule’s "sent to people or public group" box fills in.

Rules Wizard

  • Companies you write to. The wizard now suggests co-workers and companies only if you’ve written to someone there, so spam and cold sales don’t get company folders. To group every company as before, clear "Only co-workers and companies I’ve written to" on its first page.

InCloseMail 26.11.1002

Folders

  • Delete a folder with the Delete key. Select a folder (or pick several with Ctrl or Shift) and press Delete. It asks first, as Delete Folder does, including about rules that file into it.
  • Move to Spam. Right-click a folder (or several picked ones) and choose Move to Spam. They go into your own Spam folder, or into Junk Email if the mailbox has none.

Anonymous usage statistics

  • So we can count how many people use InCloseMail, it now sends a short report once a day at launch: a random install ID, the InCloseMail version, the Windows version, and whether it’s the first report. Nothing about your account, mail, contacts or files is sent. Details are on the privacy page.
  • To turn it off, clear Send anonymous usage statistics in File → Options → General. Organizations can turn it off for everyone with the new "Turn off anonymous usage statistics" Group Policy setting.

InCloseMail 26.11.1001

AI agents

  • Whole conversations. Reading a conversation now gives every message in it, from the Inbox, Sent Items and other folders, instead of only the one asked about.
  • Attachments by name. A message’s attachments are listed by their file names, not just "Attachments: yes".
  • Cleaner search results. InCloseMail’s own synced-settings message, and items in hidden folders that couldn’t be opened, no longer show up in an agent’s searches.
  • Easier-to-read mail. Earlier messages quoted in an Outlook reply are left out of a conversation, as they’re in it already. The invisible padding that marketing mail puts in its first lines is dropped, and so is a leftover "On ... wrote:" line.

Deleting folders

  • Delete Folder says what it’s doing. While it checks which rules file into the folder, the status bar says so, with the progress bar. If that takes more than 10 seconds, it asks without the rules instead of keeping you waiting.
  • "The move or copy operation failed" is fixed for a folder whose name Deleted Items already has. It goes in as "Highwinds (2)", as other same-name folders already did.

November 9, 2026

InCloseMail 26.11.914

Folders and the rules that use them

  • Deleting a folder asks about its rules. If rules file mail into it, Delete Folder names them and lets you delete them, turn them off, or keep them (and says what keeping them means: they’d file into Deleted Items, or stop working).
  • Delete several folders at once. Pick them with Ctrl or Shift and Delete Folder deletes them all ("Delete 3 Folders"), with one question.
  • Two folders with the same name can both be deleted. If Deleted Items already has a "Highwinds", the next one goes in as "Highwinds (2)" instead of failing.
  • Broken rules are flagged in Rules and Alerts: a rule whose folder is gone, or sits in Deleted Items, or that Microsoft 365 reports as broken.
  • Folders that share a name are shown by their path in rule descriptions ("Inbox › Clients › TestRail"), and the Rules Wizard no longer guesses between them.

Moving folders

  • Cut and paste folders: Ctrl+X on a folder (or several picked), then Ctrl+V on the folder to put them in. Also on the right-click menu. Esc cancels.
  • The folder pane scrolls while you drag near its top or bottom edge.
  • Moving or deleting a big folder shows how long it’s taken so far.

AI agents

  • An AI agent app started before you turned AI agents on (or opened InCloseMail) now connects as soon as it’s allowed, without restarting it.
  • File → Options → Advanced → AI agents has Select All / Select None for the mailboxes.

InCloseMail 26.11.913

InCloseMail and AI

  • Copy for AI. Right-click a message → Copy for AI copies the whole conversation as clean text: who wrote what and when, oldest first, without the quoted repeats. Paste it into ChatGPT, Claude or any other AI.
  • Export for AI. Save the selected messages, or a folder’s newest 500 (right-click the folder), as one Markdown file to give to an AI.
  • AI agents. Let AI apps on your PC that use MCP (Claude Desktop, Claude Code and others) read your mail through InCloseMail: File → Options → Advanced → AI agents.
  • Off unless you turn it on, and only while InCloseMail is open.
  • Only for you on this PC, and only for the mailboxes you tick.
  • Agents can list, search and read mail and whole conversations. They can’t send, delete or move anything.
  • If you allow it, they can save a draft for you to check and send. Mailboxes that are read-only in InCloseMail stay read-only.
  • "Copy Setup for AI Apps" gives you the settings to paste into Claude Desktop.
  • A log shows what agents asked for, never what your mail says.
  • Organizations can turn agents off with the DisableAiAgents policy.

You can see it working

  • Anything that takes more than a moment now shows a progress bar in the status bar. It fills for jobs that count (Delete All, Empty Deleted Items, Clean Up, moving or deleting many messages, moving several folders, Mark All as Read).
  • Deleting a folder says what it’s doing, such as "Deleting the folder Old Projects and its 500 items...". The server does that in one go, so a big folder takes a while.

InCloseMail 26.11.912

Move several folders at once

  • Ctrl+click folders in the folder pane to pick several, or Shift+click to pick a run of folders side by side. Drag any of them (or use Folder → Move Folder) and they all move, with one question.
  • Folders that can’t go there (Inbox and the other special folders, the folder you’re dropping onto, or a name already there) stay where they are, and you’re told which. Rules that file into the folders keep working.

Analytics: the right people in the right lists

  • A company’s newsletter is no longer listed as a co-worker; co-workers are people.
  • Deals, digests, "insider" mailings and the like count as automated mail, not people.
  • Companies are named the way their senders write them ("Canyon Freight", not "Canyonfreight"), in Analytics and in the Rules Wizard’s folders.

Demo mode

  • Everything works on the demo’s second account (Acme) too: Automatic Replies, categories, Rules and Alerts, Create Rule, the Rules Wizard and mailbox size.
  • The demo companies have logos as their account pictures.
  • A month of Acme mail now includes Wylie E. Coyote’s peace treaty with Rhoda Runner: dictated, drafted, never sent. It’s still in Drafts.

InCloseMail 26.11.911

Analytics keeps the scan you made

  • File → Analytics now opens on your newest report, whatever its period. After the Rules Wizard scans 12 months, Analytics shows those 12 months straight away instead of an older 30-day report. Picking another period shows that period’s last report.

Rules Wizard

  • Time left. Reading the Inbox and filing your mail now say how long is left at the pace so far, such as "about 8 minutes left".
  • Move your folders freely. The last page now says so: rules file mail into the folder itself, not into a place. Drag the new folders anywhere, rename them or put them inside others, and the rules keep filing into them.

InCloseMail 26.11.910

Rules Wizard improvements

  • Choose how busy a sender must be, before the lists are made. "Suggest anyone who wrote at least 10 times": pick 3, 5, 10, 15, 20, 30, 50 or 100. It applies to co-workers, companies and other senders, and your choice is remembered. A big mailbox no longer gives a long list to untick.
  • You can see it working. Create shows each step with a progress bar: setting up folders, adding rule 12 of 46, looking through the Inbox, filing their mail. Stop ends it after the step it’s on, and whatever was made stays.
  • Filing the mail already in your Inbox is much faster. It now reads only who each message is from, so a 60,000-message Inbox takes minutes instead of the better part of an hour.
  • Your existing folders move in. Folders you already have for people and companies (Inbox › Gammy, Inbox › Steve) can move into Co-workers and Companies; it’s on by default, and their mail and rules go along. A folder you keep inside another folder of yours (Alerts › PagerDuty) stays where it is.
  • New rules go after the ones you have, one at a time; any the mailbox won’t accept are listed with the reason.

Analytics

  • After the Rules Wizard scans your mail (12 months, say), File → Analytics shows that scan instead of the report it had open.

InCloseMail 26.11.909

Rules Wizard

  • Rules Wizard, next to New Rule in Rules and Alerts (and Home → Rules), makes many rules at once. It sets up a folder for each co-worker (Co-workers › Gammy) and each company you deal with (Companies › AWS), with rules that file their mail. It works for every account, added accounts included.
  • Built from Analytics. It uses the last Analytics scan, or scans now. Scanning 90 days or longer gives the best suggestions. It looks at all your folders, not only the Inbox, so people whose mail you already file away count too.
  • Knows what you have. It leaves out senders your existing rules already handle, and says how many. Where you already have a folder for someone (one by that name, or where a rule files that company’s mail), it uses that folder rather than making another. Spam and Quarantine-type folders are never used.
  • Co-workers have to be people: website contact forms, apps and Exchange’s system mailboxes aren’t offered a co-worker folder.
  • New Rule now has a tip: it’s easier to right-click a message and choose Create Rule.

Analytics remembers

  • Analytics keeps its last report. Opening it shows that report at once, with when it was made; click Refresh for the latest.

Also

  • File → Account now shows the same account as File → Info, with the same account list.
  • What’s New on the update bar has an Install now button, so you don’t have to close it first.
  • Rules and Alerts: no more "..." on the buttons. In Dark Mode the rule list no longer turns white while rules are being imported or deleted.
  • Demo: the Acme desk’s favorite customer is Wylie E. Coyote again.

InCloseMail 26.11.907

Drafts you can always finish

  • A draft opens ready to send, wherever you find it. A message saved as a draft (when InCloseMail closed to update, for example) now opens in the message form with Send. That holds in a conversation in the Inbox, in search results or in a message window, not only in Drafts.
  • "Edit draft" bar. Reading a draft in the reading pane or its own window shows "This message hasn’t been sent" with an Edit draft button.
  • You’re told when you already have a draft. Replying or forwarding in a conversation that already has your draft shows "You already have a draft in this conversation, saved …" with Open the draft. Opening it closes the new reply if you haven’t typed in it.
  • Drafts are recognized from what Microsoft 365 says about the message, not just the folder it’s in.

Demo

  • At the Acme desk, Cody Yote keeps writing to Rhoda Runner, with Acme on Cc: dinner at the big rock, a gift to open "standing exactly where the X is", a meeting halfway, a picnic with "absolutely no traps". Rhoda politely declines.
  • Demo mail no longer signs off twice.

InCloseMail 26.11.906

InCloseMail 2026.11.09, build 6.

New

  • Pick the account in Analytics. File → Analytics shows the account it’s looking at in a box at the top, with a list to pick any of your accounts. Picking one doesn’t change which account is primary. It now starts with the last 30 days, which is quicker to read.
  • More in Analytics: your reply rate (how much mail from people you answer), how much you send after hours and how much mail comes at weekends, your busiest day, and who sends you the most attachments.

InCloseMail 26.11.905

InCloseMail 2026.11.09, build 5.

New

  • File → Analytics. See your mail at a glance for the last 30 days, 90 days, 12 months or all of it:
  • Figures: mail received and sent (and how much a day), your usual reply time, what’s still unread, and what was caught as junk.
  • Charts: mail over time, your busiest hours and days, and a grid of when mail arrives each hour of the week. Pies show who your mail is from (co-workers, other people, automated senders) and how much is read.
  • Top 10s: your top senders, the co-workers who write most, the companies you hear from (with all their addresses together, so everything from AWS counts as AWS) and automated senders. Also the people and domains you write to, who you leave unread, the longest conversations, who you answer fastest and slowest, and your top 10 folders by size.

It’s all worked out on your PC from who each message is from and to and when; message text is never read, and nothing is sent anywhere.

  • Folder sizes on hover. Point at a folder in the folder pane to see its items, unread and size.

InCloseMail 26.11.904

InCloseMail 2026.11.09, build 4.

Fixed

  • Importing, starting over and deleting many rules show their progress. A progress bar says which rule is being saved ("Importing rule 37 of 196"), the other rule buttons wait until it’s done, and Stop ends it after the current rule. Closing Rules and Alerts asks before stopping. A message at the end always says what happened and lists anything left out.
  • Delete removes every selected rule. Select several with Ctrl or Shift, or all with Ctrl+A.
  • Start Over no longer stops at "object not found in the store" when a rule was already gone.

InCloseMail 26.11.903

InCloseMail 2026.11.09, build 3.

Changed

  • Pick your primary account in File → Info. The account box is now a list of your accounts. Picking one makes it your primary account: its mailbox moves to the top of the folder pane and its Inbox opens. The account’s description now sits under the box, where it can be read in full.

Fixed

  • Import Rules brings in every rule it can. A rule your mailbox won’t accept (one that names a group or a person without an email address, or has nothing left to do) no longer stops the import. The others come in, and a message lists the ones left out and why. People named without an address get theirs from your contacts where possible.

InCloseMail 26.11.902

InCloseMail 26.11.801

InCloseMail 2026.11.08, build 1.

New

  • Rules > Start Over. Rules and Alerts can save every rule to a backup file (Documents\InCloseMail\Rules backups), delete them all, and start fresh with Suggest Rules. Import Rules brings any old rule back.
  • Suggest Rules plans your folders. Besides busy senders, it suggests a folder for each colleague inside your company’s folder, and one for each company you hear from often. Select Folder Plan ticks those for you.

InCloseMail Beta, first public release version 26.11.704

A Windows email client for Microsoft 365 and Outlook.com that works the way classic Outlook does: the ribbon, the menus, the right-click options and the keyboard shortcuts you already know, for mail, calendar, contacts and tasks.

  • Mail: conversations, Focused Inbox, categories, follow-up flags, rules, Quick Steps, search folders, Advanced Find and Clean Up.
  • Calendar: day, week, month and schedule views, meetings with the Scheduling Assistant, Room Finder and Teams, shared and internet calendars.
  • People and tasks: contacts, contact groups and your Microsoft To Do tasks.
  • Several accounts at once, shared mailboxes with Send As, and Microsoft 365 Groups.
  • Offline: your mail stays on your PC, readable and searchable without a connection.
  • Your .pst files: open, import and export Outlook Data Files without Outlook.
  • Safer mail: “Why is this suspicious?” for phishing, a check before sending, S/MIME signing and encryption, and read-only mode for any account.
  • Light, dark, high contrast and holiday themes.
