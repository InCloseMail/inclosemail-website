Everything InCloseMail connects to, relies on and includes, in one place. The permissions it asks Microsoft for are explained in For administrators, and what it does with your data in the Privacy Policy.

Microsoft online services

Your mail, calendar, contacts and tasks go only between your PC and Microsoft.

  • Microsoft sign-in (login.microsoftonline.com, and Windows’ own account sign-in): signs you in and gives the app its permissions.
  • Microsoft Graph (graph.microsoft.com): almost everything. Mail, folders, rules, the calendar, contacts, Microsoft To Do, the Address Book, mailbox settings and Automatic Replies.
  • Exchange Online (autodiscover-s.outlook.com and outlook.office365.com), for work or school accounts only:
    • Finds the shared mailboxes you have access to, so they appear by themselves.
    • Sends through Exchange Online’s SMTP server, only if you turn on File → Options → Mail → Send through Exchange Online’s SMTP server.
    • Runs File → Options → Advanced → Check other ways to reach your mailbox (IMAP and SMTP), only when you click it. It reads nothing and sends nothing.

Other online services

  • GitHub (api.github.com, github.com, raw.githubusercontent.com): checks for a new version when the app starts, downloads one only when you choose to install it, and reads the beta list. Turn the check off in File → Options → General.
  • EmuKey’s usage counter (on Cloudflare): once a day, a random install ID, the app’s version and the Windows version. Never your name, address, account, mail or files. Turn it off in File → Options → General. See Privacy.
  • Google Calendar’s public holiday calendars (calendar.google.com): only when you use Add Holidays in the calendar options, to read the holidays of the countries you pick. Nothing about you is sent.
  • Internet calendars you subscribe to: read from the address you give.
  • Pictures in messages: downloaded from the sender’s servers only when you choose to. The demo mailbox’s newsletters use sample pictures from picsum.photos in the same way.
  • Links open in your web browser only when you click them.

Parts of Windows

  • .NET 10 (Microsoft, MIT License): what InCloseMail is built on. The installer includes what it needs.
  • Microsoft Edge WebView2 Runtime: shows message text and the message editor. It comes with Windows 11 and current Windows 10; if it’s missing, the app offers Microsoft’s installer (go.microsoft.com).
  • Windows’ account sign-in (Web Account Manager): the Windows sign-in window and single sign-on with the account you use for Windows.
  • Windows’ data protection (DPAPI): encrypts your sign-in and the local copy of your mailbox, so only your Windows account can read them.
  • Windows’ spell checker, notifications, speech (Read Aloud) and the certificate store (signed and encrypted mail).
