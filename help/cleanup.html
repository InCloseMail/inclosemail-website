Cleaning up years of mail

If you keep everything, your Inbox may hold 5, 10 or 20 years of mail: tens of thousands of messages, with the mail that matters buried among newsletters, notifications and junk. Clean Up My Inbox reads the whole folder, groups its mail, suggests what to do with each group, and does it all in one go. It works on any folder, and Undo All puts everything back.

A good order for a big mailbox:

  1. Start Over with your rules. This sets up a folder and rule for every co-worker and company, and files their mail. See Start over with your rules.
  2. Clean up what’s left with Clean Up My Inbox, as below.
  3. Empty Deleted Items when you’re happy with the result, to free the space.

Start it

  • Home → Clean Up My Inbox cleans up the Inbox of the mailbox you’re in.
  • Right-click any folder → Sort Through This Folder cleans up that folder instead.
  • Don’t confuse it with Clean Up Folder on the same menu. That is classic Outlook’s command, and it does something else: it removes messages whose text is quoted in full in a later reply.

It has three steps, listed on the left of its window: 1. Look, 2. Choose and 3. Clean up.

1. Look

As the window opens, InCloseMail reads every message in the folder. It reads only who sent it, when, its size, whether it’s read, and whether it was replied to, forwarded or flagged; it never reads what it says.

  • A big Inbox takes a few minutes, with a progress bar. Stop ends it.
  • InCloseMail also looks at who you write to, and at your rules, so it can leave those people alone and doesn’t suggest a rule twice.
  • Look Again starts over.

2. Choose

The folder’s mail is listed in groups, junk first and then biggest first. For each group you see how many messages it has, how many are unread, how much space they take, and the newest one.

The groups

  • Likely junk: mail Microsoft 365 rated spam or bulk mail.
  • Newsletters and marketing: a group for each sender. InCloseMail recognizes them from their unsubscribe link and from how marketing addresses look (marketing-info@…, or a mailing service’s address such as @e.company.com).
  • Other mailings: newsletters and marketing from senders with only a few messages each, gathered into one group.
  • Mail you never act on: people outside your organization you’ve never written to, and whose mail you’ve never replied to, forwarded or flagged. It works even if you mark everything read. A person row of this kind shows Never answered.
  • Co-workers: people at your own organization, one group each.
  • Companies: one group for each company you hear from, with all of its addresses together.
  • Notifications: automatic mail from no-reply addresses, alerts and the like.
  • People and senders: anyone else with a good number of messages.
  • Size and age: large messages, and mail older than 1, 2 or 5 years.

The Show list shows one kind of group at a time. Junk and mailings shows just what’s there to clear out.

What it suggests

  • Delete likely junk, newsletters and marketing from anyone you’ve never written to, other mailings, and mail you never act on.
  • Move each co-worker’s mail to Co-workers › their name, as the Rules Wizard files it. Their folder is used if you have one; otherwise it’s made inside Co-workers.
  • Mark as read unread notifications.
  • Leave alone everyone else, and anyone you’ve written to.

Change any group in its What to do list: Leave alone, Move to a folder, Archive, Delete or Mark as read. Suggested Choices puts every group back to its suggestion; Leave All Alone clears them all.

Many groups at once

  1. Pick a kind of group in Show (Newsletters, say), then click Select All. Or Ctrl+click and Shift+click groups one by one.
  2. Choose an action in Set selected to, and click Apply.

Select None clears the selection.

Moving to a folder

  • Pick any folder in the group’s Folder list. Folders inside Deleted Items, Junk Email, Drafts and the Outbox aren’t listed.
  • To make a new folder, right-click a folder in the list → New Folder Inside, or choose New folder in Inbox: and type its name. New folders are made when the clean-up runs, and every group can use them.
  • Also move future mail with a rule adds a rule, so mail that arrives later goes to the same folder. It starts ticked for newsletters and for co-workers who still write, unless a rule already files them.

A message in several groups

A message can be in several groups: its sender’s, its company’s and its age’s, for example. Each message is changed once:

  • Delete wins.
  • Then the narrowest group’s move: a sender’s folder beats a company’s.
  • Then Mark as read.

The line under the list always says what it comes to, for example “Moves 1,450 messages into 1 folder and deletes 11,971 (to Deleted Items).”

3. Clean up

  • Next > shows the summary once more. Clean Up runs it in small batches, with progress, and Stop stops between batches.
  • Deleted mail goes to Deleted Items, never straight to permanent deletion.
  • Undo All puts every message back in the folder, unread again where it was, and removes the rules and folders the clean-up made. It works after a stopped run too.
  • If your mailbox is read-only, InCloseMail asks to allow changes first.

Freeing the space

  • Deleted mail still counts toward your mailbox’s size until Deleted Items is emptied. Use File → Info → Tools → Empty Deleted Items Folder, or let Microsoft 365 empty it for you after its usual time.
  • File → Info shows how full your mailbox is, and how much of it is kept on this PC.
  • Mailbox Cleanup (File → Info → Tools) lists your folders by size and finds old or large items.

Rules on big folders

When you create a rule with Run this rule now ticked on a folder of 2,500 messages or more, InCloseMail asks first, because running it means reading every message, which can take minutes. You can:

  • run it on all of them now;
  • create the rule only, and run it later with Run Rules Now or the folder’s menu;
  • create it and sort through the folder with Clean Up instead.
