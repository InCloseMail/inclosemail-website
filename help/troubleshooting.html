Signing in

  • “Need admin approval”: your organization requires an administrator to approve the app’s permissions. Ask them to approve it for everyone in one step: For administrators has the link.
  • The status bar lists missing permissions: your organization approved only some of them. The app reads what it can, but changes can’t be turned on until the rest are approved.
  • The Windows sign-in window doesn’t appear: InCloseMail falls back to your browser.
  • To remove the app’s access: use account.microsoft.com for a personal account, or myapps.microsoft.com for a work or school account.

Sending

  • Commands ask to allow changes, or are greyed out: the account is read-only. See Read-only mode.
  • Mail comes back with “550 5.7.708”: Microsoft refuses mail that some new Microsoft 365 organizations send to outside addresses this way. Turn on File → Options → Mail → Send through Exchange Online’s SMTP server. If your organization has SMTP sign-in off, the app says how an administrator turns it on.
  • A message stays in Drafts: sending failed, and the message form says why. If you sent from another address, check that you have Send As permission.

Mail

  • The Inbox shows an unread number but you can’t find the message: it’s probably on the Other tab. The All tab shows everything.
  • Message text doesn’t show: install or repair the Microsoft Edge WebView2 Runtime.
  • A message I expected isn’t there: older mail is read from the server as you scroll down. Search looks at the server too, unless you’re offline.
  • The status bar says Working Offline: click it to try to reconnect. If you chose Work Offline yourself, click Send / Receive → Work Offline again.

Updates and the beta

  • InCloseMail checks for a new version each time it starts and shows a bar when there is one. Help → Check for Updates checks now.
  • Install now needs Windows’ admin approval. The app closes, updates and reopens.
  • Beta builds work until December 31, 2026. After that, a beta build keeps the mail on your PC readable but stops sending and receiving until you install a newer version.
  • Help → What’s New shows what changed in each release.

Getting support

  • Help → Contact Support sends us a message, with a screenshot if you like. Help → Suggest a Feature tells us what you miss from Outlook.
  • You can also email support@inclosemail.com.
  • If support asks for a log: choose File → Options → Advanced → Turn on debug logging, click OK, do what goes wrong again, then choose Send Log... there. The log never holds the content of your mail, subjects, search words or sign-in tokens.
