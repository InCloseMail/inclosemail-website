Filing mail, writing rules and sorting folders by hand is a chore. An AI agent such as Claude can do it for you: connect it to InCloseMail and it can read and search the mailboxes you choose, draft replies, translate mail written in other languages, and propose folders, rules and cleanups. You see every proposed change with the agent’s reason, and nothing changes until you click Apply. Undo puts it all back.

It works with Claude Desktop, Claude Code and any other AI app that uses the Model Context Protocol (MCP). InCloseMail never sends mail for an agent.

Turn it on

  1. Open File → Options → Advanced and find AI agents.
  2. Check Let AI agents on this PC read my mail through InCloseMail.
  3. Under Mailboxes they may use, uncheck any mailbox the agent should stay out of: for example, an added account or a shared mailbox.
  4. To let the agent write drafts for you, check Let them save drafts in Drafts for me to check and send.
  5. Click OK.

It’s off until you turn it on, and it works only while InCloseMail is open, only for you on this PC.

Connect your AI app

In the same place, InCloseMail gives you what your AI app needs. Either way, the app starts InCloseMail’s small agent bridge, which connects it to the InCloseMail you have open. InCloseMail keeps the bridge in your AppData folder, where updates don’t touch it, so your AI app stays connected while InCloseMail updates and picks up again when it starts.

Claude Code: one click

  1. Click Connect Claude Code. InCloseMail shows a short message, already filled in for your PC.
  2. Click Copy Message, paste it into Claude Code (the app or the terminal) and send it. Claude sets up the connection and checks that it works.
  3. Start a new session in Claude Code and ask it about your mail.

If you’d rather do it yourself, the message boils down to running this once in a terminal (your path may differ):

claude mcp add --scope user inclosemail -- "C:\Users\you\AppData\Local\InCloseMail\AgentBridge\InCloseMail.AgentBridge.exe" --mcp

Claude Desktop

  1. Click Copy Setup for Claude Desktop in InCloseMail. It puts the settings on the clipboard.
  2. In Claude Desktop, open Settings → Developer → Edit Config. This opens claude_desktop_config.json.
  3. Paste the settings in. If the file already has an mcpServers section, add the inclosemail entry to it rather than pasting a second one.
  4. Save the file and restart Claude Desktop. InCloseMail then shows in its list of connectors.

The settings look like this (your path may differ):

{
  "mcpServers": {
    "inclosemail": {
      "command": "C:\\Users\\you\\AppData\\Local\\InCloseMail\\AgentBridge\\InCloseMail.AgentBridge.exe",
      "args": [ "--mcp" ]
    }
  }
}

Other AI apps

Any app that can start a local MCP server can use InCloseMail: give it the command InCloseMail.AgentBridge.exe (in %LOCALAPPDATA%\InCloseMail\AgentBridge) with the argument --mcp, as in the settings above.

What an agent can do

  • Read: list your mailboxes and folders, list and search messages (as the search box does, with from:, subject: and so on), and read a message or a whole conversation. Messages reach the agent as clean text, without the quoted earlier replies.
  • Read your rules: each rule in the order it runs, what it looks for and what it does.
  • See how full a mailbox is: its size, its limits, how much is used and its 10 largest folders. See When your mailbox is full.
  • Translate: show its translation of a message in InCloseMail, in place of the original. See Translate mail.
  • Save drafts in Drafts, if you allowed it. You check them and send them yourself. Never in a mailbox that is read-only in InCloseMail.
  • Propose changes for you to approve. See below.

An agent can never send mail, and it can’t change anything on its own.

Let it organize your mail

Ask the agent in your own words, for example:

  • “Look at my Inbox and suggest folders and rules for the mail I get most.”
  • “File everything from Linode and PhoenixNAP status pages into their own folders, and make rules for new mail.”
  • “Find newsletters I never open and clear them out.”
  • “My rules have grown messy. Tidy them up.”

The agent looks first (your folders, rules and mail), then sends one proposal. It can propose:

  • Folders: make, rename or move a folder; put a folder, with its mail and subfolders, in Deleted Items; or merge two folders (all the mail of one moves to the other, however much there is, and the emptied folder goes to Deleted Items). The proposal shows how many messages and subfolders go with each one. It won’t take away a folder a rule still files into unless that rule goes too, a folder already in Deleted Items, or folders Outlook keeps for itself, such as Sync Issues.
  • Rules: add a rule (who it’s from, words in the subject or body, who it was sent to, with exceptions; move it, mark it as read, categorize it or put it in Deleted Items), and run a new rule on mail already in a folder. Turn rules on or off, delete them, or change their order.
  • Mail: move messages, mark them as read, or put them in Deleted Items (up to 500 messages per change; for more, it proposes a rule and runs it).

Review it

InCloseMail opens the proposal in its own window, with the agent’s summary at the top and a list of changes. The window’s title says which proposal it is, what it’s about and when it came, for example p3 · File the Linode mail · 3:31 AM. Each change says what it does, in plain words, with the agent’s Why. For messages, it shows a few of their subjects.

  • Every change starts checked. Uncheck any you don’t want. Select All and Clear All do them all.
  • Apply makes the checked changes: folders first, then rules (in one save), then mail, and last the folders that are deleted or merged. If one doesn’t work, it says why in red under that change, and the rest still go ahead. A very large folder can take the server longer than one request allows: InCloseMail then checks whether it got to Deleted Items anyway, and tries again if it didn’t (“attempt 2 of 3”).
  • After Apply, each change says what happened to it: Made, Partly made (with how far it got, such as how many messages a new rule moved before you canceled), Not made (and why), or, after Undo, Undone.
  • Decline changes nothing. Before Apply, Cancel and closing the window do the same.
  • If the mailbox is read-only in InCloseMail, Apply asks to allow changes first, as any change does.
  • While Apply runs, it counts as it goes (“Reading the messages: 2,000 of 28,247”, then “4,200 of 28,247 messages moved”), so you can see it’s working. Cancel (or closing the window) stops it after the step it’s on. The window stays open and says what was made and what wasn’t, and Undo puts back what was made.
  • The agent is told what happened (applied, partly applied, failed, canceled, declined or undone), with how far a long job has got and, for each change that didn’t work, why, so it can explain and suggest a fix.
  • When an agent sends several proposals, they’re steps, applied in the order they came: each window says Step 2 of 3 from Claude Code, the oldest stays in front, and a later one’s Apply waits until the ones before it are applied or declined. An agent can also say that a proposal needs another one applied first, or ask you to do something first that InCloseMail can’t check (“Before you apply, Claude Code says: after Deleted Items is emptied”).
  • If you ask the agent for something different while a proposal is still open, it sends a revised one that takes the old one’s place in the same window, marked Updated proposal (replaces p1). It can also withdraw a proposal that’s still open: the window closes, and the status bar says why. A proposal you’ve applied or declined stays as it is.

You can keep working in InCloseMail while the window is open.

When your mailbox is full

A mailbox at its size limit refuses to take mail into its folders, so moves and rules that file mail fail (Exchange’s words: “exceeded its storage quota”). The agent can see how full your mailbox is and which folders are largest, and puts the changes that free space first when it’s nearly full.

  • Apply checks the mailbox’s size first. If it’s full, nothing starts: the window says so, for example “This mailbox is full (52.1 GB of 49.5 GB). Moving mail may fail. Empty Deleted Items or remove large folders first.” Click Apply anyway to go ahead (deleting mail still works), or Cancel to decline it and free some space first.
  • When it’s nearly full, the window says so and Apply goes ahead.
  • A change that fails says why in plain words under it, with what to do next. If Outlook showed Rules in Error at the same time, the window explains that too: it’s the same problem.
  • The size limit comes from Exchange when it gives one, else from File → Options → Mail → Mailbox size, else from your Microsoft 365 plan.

Undo

After Apply, Undo puts things back as they were:

  • the rules it touched go back to how they were, and new rules are removed;
  • moved messages go back to their folders, and messages it marked as read are unread again;
  • new folders go to Deleted Items, if they’re still empty;
  • deleted folders come back from Deleted Items to where they were, with their own names, and merged mail goes back to its folder.

One exception: when a new rule does more than move or delete mail by sender or subject, InCloseMail runs it as Run Rules Now does, and Undo can’t bring that mail back. The window says so after Apply.

Nothing is ever deleted for good: mail goes to Deleted Items, which you empty yourself.

Clean up your whole account

InCloseMail has tools for tidying by hand: Clean Up My Inbox, the Rules Wizard and Start over with your rules. They still work, but you don’t need them. With an agent connected, you can describe the account you want in a few sentences and let it do the whole job: it reads your folders, rules and mail, works out a plan, and proposes the changes. You only check and apply them.

Why this works well:

  • It sees the whole account at once. It notices that three folders hold the same company’s mail, that a rule files into a folder you renamed, or that half your Inbox is status alerts.
  • You say what you want, not how. “Keep anything from real people, file the rest by company” is enough. The agent turns it into folders, rules and moves.
  • Nothing changes until you say so. Each step is a proposal with a reason on every change, and Undo puts it back.

Tell it what you want

The more the agent knows about how you work, the better its plan. A good request says what you want to end up with, what matters to you, and what to leave alone. For example:

“Clean up my whole mailbox. I want a short Inbox with only mail from real people and things I have to act on. File everything else into folders by company, under one Companies folder. Status pages and alerts (Linode, PhoenixNAP, Atlassian) go in their own folders and are marked as read. Newsletters I haven’t opened in a year can go to Deleted Items. Tidy my rules too: merge the ones that do the same thing and remove ones that file into folders I no longer use. Don’t touch my Clients folder or anything from my accountant. Tell me your plan before you propose anything.”

Shorter requests work too:

  • “I want to start cleaning up and organizing my you@example.com email account in InCloseMail.”
  • “Look at my whole account and tell me what you’d clean up. Don’t change anything yet.”
  • “I have 20 years of mail in my Inbox. Sort it into a sensible set of folders, with rules so it stays that way.”
  • “My folders are a mess. Suggest a simpler structure and move things into it.”
  • “Find rules that never match anything or file into folders I don’t use, and remove them.”
  • “Check what landed in my Inbox this month and suggest rules for anything that keeps coming.”

How it goes

  1. Ask for the plan first. The agent looks through your folders, rules and mail and tells you what it found and what it would do. Talk it over and change anything you don’t like before it proposes a thing.
  2. Go a step at a time. A big account takes a few proposals: for example, folders first, then rules, then the old mail. Each proposal holds up to 100 changes; each change moves up to 500 messages, and for more the agent proposes a rule and runs it on the folder, or merges the whole folder into another.
  3. Check each proposal in the AI Agent Proposal window, uncheck anything you don’t want, and click Apply. The agent is told what you applied, so it can continue with the next step.
  4. Look at the result in InCloseMail. If a step went wrong, click Undo in its window, or tell the agent what to change.
  5. Empty Deleted Items yourself when you’re happy. Until then nothing is gone.

Afterward, your rules keep new mail where it belongs, as they always have; the agent only wrote them for you. Every month or so, ask it to look again.

Good to know

  • What it reads goes to your AI app’s provider. A whole-account cleanup means the agent reads a lot of your mail. If you’d rather it didn’t read the messages themselves, ask it to work from senders and subjects only, and uncheck any mailbox it shouldn’t see. See Your privacy.
  • It can’t empty Deleted Items. Folders it deletes go there, like mail, and stay until you empty it. Undo brings them back until then.
  • It changes a rule by replacing it: a new rule in its place, and the old one deleted. Both show in the proposal.
  • Mail filed by a new rule run on a folder can’t always be undone (see Undo). For a large cleanup, ask the agent to say which changes those are.

Translate mail

Got a message in a language you don’t read? Select it in InCloseMail and ask the agent, for example:

  • “Translate the email I have open.”
  • “Translate the latest message from Lukas into English.”

The agent reads the message, translates it, and InCloseMail shows the translation in place of the original, in the Reading Pane and in the message’s own window, subject included. A bar above it says who translated it and from what language. Click Show original to see the message as it came, and Show translation to go back.

Nothing in your mailbox changes: the translation is only on your screen, and it lasts until you close InCloseMail. The agent translates into your language unless you ask for another. To reply in the sender’s language, ask it to draft the reply.

Your privacy

  • Only the mailboxes you checked, only while InCloseMail is open, and only AI apps running on this PC as you.
  • What you let the agent read goes to that AI app, and from there to its provider (Anthropic, for Claude), under the app’s own terms. InCloseMail sends nothing anywhere else.
  • Open Log (next to Copy Setup for Claude Desktop) shows what agents asked for and when: which tool and which mailbox, never what the mail says. At 5 MB it starts over; the one before is kept as ai-agents.1.log in the same folder.
  • Uncheck the AI agents box to cut every agent off at once.

Without connecting an app

To use a chatbot in your browser instead, give it text yourself:

  • Right-click a message → AI → Copy for AI copies the whole conversation as clean text (who wrote what and when, without the quoted repeats), to paste into ChatGPT, Claude or any other AI.
  • Right-click messages → AI → Export for AI saves the selected messages in full as one Markdown file.
  • Right-click a folder → Export → Export Folder for AI saves its newest messages (up to 500) the same way.

For administrators

To keep AI agents off for everyone, use the Turn off AI agents policy (registry value DisableAiAgents, 1, under SOFTWARE\Policies\InCloseMail) in InCloseMail’s Group Policy and Intune templates. File → Options then says your organization has turned them off. Copy for AI and Export for AI stay, as they only make text the person chooses to paste or save. See For administrators.

If it doesn’t work

  • The agent says InCloseMail isn’t running, or AI agents are off: open InCloseMail, check the box in File → Options → Advanced → AI agents, and ask again.
  • InCloseMail doesn’t show in Claude Desktop: check the config file is valid JSON (one mcpServers section, commas between entries), then restart Claude Desktop completely (from the tray icon too).
  • Claude Code doesn’t see InCloseMail: start a new Claude Code session after connecting (a session that was already open doesn’t pick it up). Running claude mcp get inclosemail in a terminal shows whether it’s set up and connected; if not, click Connect Claude Code again and send the message once more.
  • A mailbox is missing: it’s unchecked under Mailboxes they may use, or isn’t open in InCloseMail.
  • Drafts aren’t saved: select the drafts box, and check the mailbox isn’t read-only.
  • During an update your AI app stays connected, and InCloseMail answers again as soon as it’s back. If you set up your AI app before the agent bridge came (its setup names Program Files\InCloseMail\InCloseMail.exe), an update ends its connection: click Connect Claude Code again (or copy the new setup) once, and it stays connected from then on.
