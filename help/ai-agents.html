Filing mail, writing rules and sorting folders by hand is a chore. An AI agent such as Claude can do it for you: connect it to InCloseMail and it can read and search the mailboxes you choose, draft replies, translate mail written in other languages, and propose folders, rules and clean-ups. You see every proposed change with the agent’s reason, and nothing changes until you click Apply. Undo puts it all back.

It works with Claude Desktop, Claude Code and any other AI app that uses the Model Context Protocol (MCP). InCloseMail never sends mail for an agent.

Turn it on

  1. Open File → Options → Advanced and find AI agents.
  2. Tick Let AI agents on this PC read my mail through InCloseMail.
  3. Under Mailboxes they may use, untick any mailbox the agent should stay out of: an added account, or a shared mailbox, say.
  4. To let the agent write drafts for you, tick Let them save drafts in Drafts for me to check and send.
  5. Click OK.

It’s off until you turn it on, and it works only while InCloseMail is open, only for you on this PC.

Connect your AI app

In the same place, Copy Setup for AI Apps puts the settings an AI app needs on the clipboard. They tell the app to start InCloseMail with --mcp, which connects it to the InCloseMail you have open.

Claude Desktop

  1. Click Copy Setup for AI Apps in InCloseMail.
  2. In Claude Desktop, open Settings → Developer → Edit Config. This opens claude_desktop_config.json.
  3. Paste the settings in. If the file already has an mcpServers section, add the inclosemail entry to it rather than pasting a second one.
  4. Save the file and restart Claude Desktop. InCloseMail then shows in its list of connectors.

The settings look like this (your path may differ):

{
  "mcpServers": {
    "inclosemail": {
      "command": "C:\\Program Files\\InCloseMail\\InCloseMail.exe",
      "args": [ "--mcp" ]
    }
  }
}

Claude Code

Run this once in a terminal:

claude mcp add inclosemail -- "C:\Program Files\InCloseMail\InCloseMail.exe" --mcp

Other AI apps

Any app that can start a local MCP server can use InCloseMail: give it the command InCloseMail.exe with the argument --mcp, as in the settings above.

What an agent can do

  • Read: list your mailboxes and folders, list and search messages (as the search box does, with from:, subject: and so on), and read a message or a whole conversation. Messages reach the agent as clean text, without the quoted earlier replies.
  • Read your rules: each rule in the order it runs, what it looks for and what it does.
  • Translate: show its translation of a message in InCloseMail, in place of the original. See Translate mail.
  • Save drafts in Drafts, if you allowed it. You check them and send them yourself. Never in a mailbox that is read-only in InCloseMail.
  • Propose changes for you to approve. See below.

An agent can never send mail, and it can’t change anything on its own.

Let it organize your mail

Ask the agent in your own words, for example:

  • “Look at my Inbox and suggest folders and rules for the mail I get most.”
  • “File everything from Linode and PhoenixNAP status pages into their own folders, and make rules for new mail.”
  • “Find newsletters I never open and clear them out.”
  • “My rules have grown messy. Tidy them up.”

The agent looks first (your folders, rules and mail), then sends one proposal. It can propose:

  • Folders: make, rename or move a folder.
  • Rules: add a rule (who it’s from, words in the subject or body, who it was sent to, with exceptions; move it, mark it as read, categorize it or put it in Deleted Items), and run a new rule on mail already in a folder. Turn rules on or off, delete them, or change their order.
  • Mail: move messages, mark them as read, or put them in Deleted Items (up to 500 messages per change; for more, it proposes a rule and runs it).

Review it

InCloseMail opens the proposal in its own window, AI Agent Proposal, with the agent’s summary at the top and a list of changes. Each change says what it does, in plain words, with the agent’s Why. For messages, it shows a few of their subjects.

  • Every change starts ticked. Untick any you don’t want. Select All and Clear All do them all.
  • Apply makes the ticked changes: folders first, then rules (in one save), then mail. If one doesn’t work, it says why in red under that change, and the rest still go ahead.
  • Decline changes nothing. Closing the window without applying does the same.
  • If the mailbox is read-only in InCloseMail, Apply asks to allow changes first, as any change does.
  • The agent is told what happened (applied, partly applied, declined or undone), so it can carry on.

You can keep working in InCloseMail while the window is open.

Undo

After Apply, Undo puts things back as they were:

  • the rules it touched go back to how they were, and new rules are removed;
  • moved messages go back to their folders, and messages it marked as read are unread again;
  • new folders go to Deleted Items, if they’re still empty.

One exception: when a new rule does more than move or delete mail by sender or subject, InCloseMail runs it as Run Rules Now does, and Undo can’t bring that mail back. The window says so after Apply.

Nothing is ever deleted for good: mail goes to Deleted Items, which you empty yourself.

Translate mail

Got a message in a language you don’t read? Select it in InCloseMail and ask the agent, for example:

  • “Translate the email I have open.”
  • “Translate the latest message from Lukas into English.”

The agent reads the message, translates it, and InCloseMail shows the translation in place of the original, in the Reading Pane and in the message’s own window, subject included. A bar above it says who translated it and from what language. Click Show original to see the message as it came, and Show translation to go back.

Nothing in your mailbox changes: the translation is only on your screen, and it lasts until you close InCloseMail. The agent translates into your language unless you ask for another. To reply in the sender’s language, ask it to draft the reply.

Your privacy

  • Only the mailboxes you ticked, only while InCloseMail is open, and only AI apps running on this PC as you.
  • What you let the agent read goes to that AI app, and from there to its provider (Anthropic, for Claude), under the app’s own terms. InCloseMail sends nothing anywhere else.
  • Open Log (next to Copy Setup) shows what agents asked for and when: which tool and which mailbox, never what the mail says.
  • Untick the AI agents box to cut every agent off at once.

Without connecting an app

To use a chatbot in your browser instead, give it text yourself:

  • Right-click a message → Copy for AI copies the whole conversation as clean text (who wrote what and when, without the quoted repeats), to paste into ChatGPT, Claude or any other AI.
  • Right-click messages → Export for AI saves the selected messages in full as one Markdown file.
  • Right-click a folder → Export Folder for AI saves its newest messages (up to 500) the same way.

For administrators

To keep AI agents off for everyone, use the Turn off AI agents policy (registry value DisableAiAgents, 1, under SOFTWARE\Policies\InCloseMail) in InCloseMail’s Group Policy and Intune templates. File → Options then says your organization has turned them off. Copy for AI and Export for AI stay, as they only make text the person chooses to paste or save. See For administrators.

If it doesn’t work

  • The agent says InCloseMail isn’t running, or AI agents are off: open InCloseMail, check the box in File → Options → Advanced → AI agents, and ask again.
  • InCloseMail doesn’t show in Claude Desktop: check the config file is valid JSON (one mcpServers section, commas between entries), then restart Claude Desktop completely (from the tray icon too).
  • A mailbox is missing: it’s unticked under Mailboxes they may use, or isn’t open in InCloseMail.
  • Drafts aren’t saved: tick the drafts box, and check the mailbox isn’t read-only.
  • During an update the connection closes so the update can install; your AI app connects again afterwards.
