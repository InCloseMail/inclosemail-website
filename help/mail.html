Reading mail

  • Click a message to read it in the reading pane. Double-click it, or press Enter, to open it in its own window.
  • Use View → Reading Pane to put the pane on the right, at the bottom, or turn it off.
  • Pictures from the web are blocked until you click Download pictures.
  • Files that can run code, such as .exe and .js files, are blocked, as they are in Outlook.
  • File → Options → Mail sets when a message counts as read: right away, after waiting, or when you select another message.

Focused Inbox

The Inbox of each of your accounts has three tabs. Focused and Other split your mail by Microsoft’s own classification, so each one hides the other’s messages. All shows the whole Inbox. The number beside Inbox counts everything, and the number beside Other shows how many of those unread messages are on that tab.

  • Right-click a message for Move to Other or Move to Focused.
  • Always Move to Other or Always Move to Focused puts that sender’s new mail on that tab everywhere, including Outlook on the web.
  • To turn the tabs off, clear View → Show Focused Inbox. Shared mailboxes and other folders show All and Unread instead.

Writing mail

  • New Email is Ctrl+N, and Ctrl+Shift+M from anywhere. Reply is Ctrl+R, Reply All Ctrl+Shift+R and Forward Ctrl+F.
  • A new message is From the address chosen in File → Options → Mail → Start new messages from; the From list marks it (Default), and the gear beside it opens that option. Left on Automatic, it’s the mailbox at the top of the folder pane. A reply or forward is from the account the message came to. Pick another in the From list.
  • Auto-Complete: as you type a name in To, Cc or Bcc, InCloseMail suggests people from all your accounts: those you’ve written to and your contacts, the From account’s first. After a moment it also looks in your organization’s directory, so a colleague turns up even if you’ve never written to them. The first time, click To in a message from that account and allow the Address Book. Up and Down pick a suggestion, Enter or Tab takes it, and the X removes it from the list.
  • Send with Send, Ctrl+Enter or Alt+S. A message can carry up to 20 MB of attachments.
  • Drafts save themselves every 3 minutes. File → Options → Mail changes that.
  • Signatures: Insert → Signature → Signatures... Set the defaults for new messages and for replies there.
  • Send later: Options → Delay Delivery. Exchange holds the message in the Outbox, so it goes out even with InCloseMail closed.
  • Quick Parts and templates: Insert → Quick Parts and Message → View Templates. Both are kept on this PC.
  • AutoCorrect fixes common typos as you type, capitalizes sentences, curls quotes, turns (c) into © and -- into a dash, starts a list from * or 1., and makes web and email addresses links. Ctrl+Z right after takes a change back. Turn each one off in File → Options → Mail → AutoCorrect and pasting.
  • Paste (Message tab) has Keep Source Formatting, Merge Formatting, Keep Text Only and Paste Special (Ctrl+Alt+V). After a paste, the (Ctrl) button beside it pastes again the way you choose.
  • Before sending, InCloseMail warns about a reply to 20 or more people, outside recipients on a message that also goes to colleagues, and an attachment you mentioned but didn’t attach. Turn this off in File → Options → Mail.

Organizing mail

  • Delete moves messages to Deleted Items. Shift+Delete skips Deleted Items, after asking. Backspace archives.
  • Undo (Ctrl+Z) takes back your last moves, deletes, flags and categories, up to 20 of them.
  • Follow Up flags messages. Insert flags for today.
  • Categorize adds color categories. In All Categories you can give one a shortcut key.
  • Quick Steps (Home tab) run several actions with one click. Give one a shortcut in Manage Quick Steps.
  • Clean Up and Ignore (Home tab) deal with long conversations.
  • View → Show as Conversations threads the list. View → Clean Conversation View reads a whole conversation like a chat in the reading pane.
  • File → Info → Tools → Mailbox Cleanup shows how big your mailbox and its folders are, and finds old or large items to delete or archive. Archive Old Items there, and AutoArchive in File → Options → Advanced, move old mail to the Archive folder.
  • In a message’s own window, Actions → Edit Message lets you change a message you received (to add notes, say), then Save (Ctrl+S). Actions → View in Browser opens it in your web browser.
  • File → Print (Ctrl+P) shows how the message will print before you print it.
  • Replying to an older message in a conversation says so, with a link to the latest one. File → Options → Mail can write replies in the reading pane instead of a new window (turn off Open replies and forwards in a new window).
  • Type @ and a name in a message to mention someone; they’re added to To.
  • File → Options → Mail → Tracking decides whether to send read receipts: ask each time (the default), always, or never.
  • To open email links in InCloseMail, choose it in File → Options → General → Default Programs.
  • Folder → Recover Deleted Items brings back what was deleted from Deleted Items, for a while afterwards.

Search

  • Ctrl+E puts the cursor in the search box. Results appear as you type. Esc goes back to the folder.
  • The Search tab sets the scope: Current Folder, Subfolders, Current Mailbox or All Mailboxes.
  • You can type criteria alongside words, such as from:"Megan", hasattachments:yes or read:no.
  • Advanced Find is Ctrl+Shift+F. New Search Folder is Ctrl+Shift+P.
  • File → Options → Search sets how many results show and whether Deleted Items is included.

Rules

Home → Rules → Manage Rules & Alerts... lists your rules. Create Rule... starts one from the selected message. On mail in an added account, it makes a rule in that account. Rules are kept and run by Exchange, so they work with InCloseMail closed and show in Outlook on the web. Run Rules Now applies them to mail already in a folder, but never forwards it. Export Rules and Import Rules move your rules to another mailbox.

Script rules

Home → Rules → Script Rules... runs a script of yours when matching mail arrives, as classic Outlook’s “run a script” rule did, with a script file instead of VBA. A rule can watch your Inbox, an added account’s or a shared mailbox’s, and match on the sender, the subject and whether there are attachments. The script can be a PowerShell script (.ps1), a batch file (.cmd or .bat) or a program (.exe).

  • The script gets one argument: the path of a JSON file with the message’s details (subject, fromAddress, fromName, to, cc, received, hasAttachments, bodyPreview, internetMessageId, mailbox and emlPath, where the whole message is saved as an .eml file). Both files are deleted when the script ends.
  • Nothing from the message is put on the script’s command line, so a crafted subject can’t run anything.
  • PowerShell scripts run only if they were made on this PC or are signed (the RemoteSigned policy); a downloaded unsigned script doesn’t run.
  • Rules run while InCloseMail is open, on the new mail it finds, and are kept on this PC. Run Now tries a rule on the selected message.

A short example, saving each matching message as an .eml file in a folder:

param($Path)
$m = Get-Content -Raw -LiteralPath $Path | ConvertFrom-Json
Copy-Item -LiteralPath $m.emlPath -Destination "C:\Invoices\$($m.internetMessageId.Trim('<>')).eml"

Junk mail and phishing

  • Home → Junk has Block Sender, Never Block Sender, Not Junk and Junk E-mail Options.
  • InCloseMail’s Safe Senders list is kept on this PC and works while the app is running. For filtering that works everywhere, also add senders in Outlook on the web.
  • When a message has signs of phishing, a bar appears above it. Click Why is this suspicious? for the reasons and what to do. Block Sender and I know this sender are there too. The bar never moves or blocks anything by itself.
