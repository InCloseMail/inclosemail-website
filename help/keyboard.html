InCloseMail uses Outlook’s keys. These are the ones people use most.

You can change them: File → Options → Keyboard Shortcuts lists the commands of the main window, of a message opened in its own window and of writing a message, each with its keys. This page lists Outlook’s keys, the defaults, so if you’ve changed some, Options shows yours. See Your own keyboard shortcuts.

Ribbon key tips

Press Alt or F10 and each tab and command shows its letters, as in Outlook. For example, Alt, H, R, P replies and Alt, H, D deletes.
