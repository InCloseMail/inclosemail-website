Read-only mode

InCloseMail can change your mailbox from the start, as any mail app does. If you’d rather an account stay as it is, to look around first or for a mailbox you only check, make it read-only: InCloseMail then doesn’t send, move, delete or mark anything, and opening a message doesn’t mark it as read. The status bar shows Mode: Read/Write or Mode: Read Only for the account you’re looking at.

  • To make an account read-only, clear File → Options → Mail → Allow changes to my mailbox. Commands that change the mailbox, such as New Email, then ask before allowing changes again.
  • To allow only some kinds of change, choose Custom there and tick the ones you want.
  • To make sure an account never changes, choose Keep this account read-only. Commands that would change it are grayed out.
  • To allow changes again, click a command such as New Email and answer Yes, or select Allow changes to my mailbox.

The choice is remembered for each account. Clicking Mode in the status bar opens these settings.

More than one account

File → Add Account opens another work, school or Outlook.com account beside yours (Switch Account is different: it replaces the account you signed in with first, and the accounts added beside it), with its mail in the folder pane and its address in the From list. New messages start From whichever mailbox is at the top of the folder pane, unless you pick one in File → Options → Mail → Start new messages from; Auto-Complete suggests people from every account, and Create Rule works on its mail too (see Writing mail and Rules). Its contacts show under My Contacts in People, and its task lists under My Tasks, each with the account’s address. Right-click an added account for Remove Account. To change the order of the mailboxes, drag one up or down in the folder pane, or right-click it for Move Up and Move Down. File → Options → Mail sets each account to read-only or to allow changes, separately.

If an added account can’t sign in by itself (your organization removed InCloseMail, say, or the password changed), its mail stays on your PC. Whether this happens at startup or while InCloseMail is open, the account leaves the folder pane, the status bar says so, and Microsoft’s sign-in doesn’t open by itself. File → Account lists it under Accounts that need you to sign in again, with Sign In Again and Remove. It also signs in by itself again once access comes back. If it isn’t signed in again within 30 days, its mail is removed from your PC.

Profiles

A profile is a separate set of accounts with its own settings, signatures and copy of your mail, as in classic Outlook: one for work and one for home, say. InCloseMail opens one profile at a time. Everyone starts with one, named InCloseMail.

  • To add one, go to File → Info → Account Settings → Manage Profiles and click Add. InCloseMail offers to start with it now; a new profile starts signed out, so you sign in to its account there.
  • To switch, choose File → Info → Account Settings → Change Profile. InCloseMail closes and opens again with Choose Profile. While a profile is signed out, the same commands are under Profiles on File → Info.
  • To be asked every time, choose Prompt for a profile to be used in Manage Profiles; or choose Always use this profile and pick one. Set as default profile in Choose Profile does the same.
  • Copy makes a new profile with the same accounts and settings; its mail is downloaded again. Remove deletes a profile’s sign-in, settings and mail on this PC (the mailbox itself isn’t touched). The profile you’re using, and the first one, can’t be removed.
  • From a shortcut or script, InCloseMail.exe --profile "Work" starts with that profile (/profile works too, as with Outlook).

Shared mailboxes

  • Shared mailboxes you have Full Access to usually appear by themselves. If a bar offers it, click Allow, or right-click your mailbox and choose Find Shared Mailboxes.
  • To add one by hand, right-click your mailbox and choose Add Shared Mailbox. A new permission can take up to an hour to work.
  • A shared mailbox shows an S tag beside its name. File → Options → Mail → Shared mailboxes changes how it’s marked.
  • To send from one, pick it in the message form’s From list. You need Send As or Send on Behalf permission.
  • The From list also offers your account’s aliases (its other addresses). Point at an address to see whether it’s a shared mailbox or an alias. Mail goes out from an alias only if your organization allows sending from aliases; otherwise it goes out from your main address.
  • Messages can’t be moved or copied between mailboxes.

Shared mailboxes are for work and school accounts.

Offline and the local copy

InCloseMail keeps a copy of your recent mail on this PC, encrypted for your Windows user. By default that’s 30 days of the folders you’ve opened and the messages you’ve read, plus your calendar from a month back to three months ahead. Attachments and contacts aren’t stored. Signing out deletes the copy.

  • File → Options → Advanced → Mail kept on this PC changes how much is kept.
  • Send / Receive → Work Offline stops all sending and receiving until you click it again.
  • If your connection drops, the app goes offline by itself and reconnects when it can. Changes to your mailbox are off until then.

Send/Receive

New mail arrives by itself: the Inbox is checked often, and every folder every 30 minutes. F9 checks all folders now and Shift+F9 the current one. Send / Receive → Send/Receive Groups → Define Send/Receive Groups changes the timing.

Your settings on every PC

If you use InCloseMail on more than one PC, your settings follow you: your options and views, Safe Senders, Quick Steps, Favorites, contact groups, the shared mailboxes and calendars you added, signatures, templates and Quick Parts. They’re kept in your mailboxes, in a folder Outlook doesn’t show, and your other PCs pick them up within 5 minutes, or as soon as you bring InCloseMail to the front; some take effect the next time InCloseMail starts. Change one thing on each PC and both changes are kept; if both PCs change the same list, such as Safe Senders, before they sync, the two are combined. The first time a second PC joins, its lists are combined with yours too.

Window sizes, sign-ins, added accounts and the settings for the copy of your mail stay on each PC. While changes to your mailbox are turned off on a PC, it takes the other PCs’ settings but shares none of its own; File → Options → Advanced says so. To turn syncing off on a PC: File → Options → Advanced → Keep my settings the same on every PC.

Which mailboxes: every account on a PC keeps a copy of the settings in its mailbox, and InCloseMail passes changes between them. So two PCs share settings as long as they have at least one account in common, whichever account each signed in with first; adding or removing an account doesn’t cut a PC off. The first time a mailbox meets a PC’s settings, lists such as custom themes and Safe Senders are combined, and for single settings the newer one wins. To keep your settings in one account’s mailbox only, pick it under File → Options → Advanced → Settings on your other PCs → Keep them in the mailbox of (the default is Every account on this PC).

Check Sync Now, on the Send / Receive tab and under the same heading in Options, syncs right away and shows which mailboxes this PC uses, and for each of your accounts whether its mailbox holds settings, how many custom themes they include, and which PC saved them last.

Starting with Windows

File → Options → Advanced → Start InCloseMail when Windows starts opens InCloseMail when you sign in to Windows. Tick Start minimized as well to have it wait on the taskbar; when you open it, it comes back as you left it. Task Manager’s Startup tab shows it and can turn it off too. Each Windows user sets this for themselves.

Moving to a new PC

Install InCloseMail on the new PC and sign in with the same account. Don’t copy the InCloseMail folder from your old PC (%LOCALAPPDATA%\InCloseMail). Your sign-in and the copy of your mail in it are encrypted for your Windows user on the old PC, and the new PC can’t read them. You’d have to sign in again anyway, and InCloseMail would set the copy it can’t read aside (where it takes up space for 30 days) and download your mail again.

What comes across by itself:

  • Your mail, calendar, contacts, tasks, rules, categories and Automatic Replies. They’re in your mailbox. The copy kept for offline use downloads again; for a large mailbox that can take a few hours, and you can use InCloseMail meanwhile.
  • Your options and views, Safe Senders, Quick Steps, Favorites, contact groups, the shared mailboxes and calendars you added, signatures, templates and Quick Parts, through Your settings on every PC, as long as it’s on on your old PC (it is unless you turned it off). They arrive within a few minutes of signing in; some take effect the next time InCloseMail starts. If the old PC is still around, open InCloseMail there once before you switch, so its latest changes are saved.

What to set again on the new PC:

  • Other accounts: File → Add Account for each one.
  • .pst files: copy them across, then File → Open & Export → Open Outlook Data File.
  • Settings kept per PC: how much mail is kept on this PC, read-only choices, starting with Windows, script rules, AI agents and debug logging.
  • Rules backups you saved (in Documents\InCloseMail\Rules backups) and any exported files are ordinary files: copy them if you want them.

Uninstalling

Help → Uninstall, or Windows’ Settings → Apps, removes InCloseMail. Your mail, calendar and contacts stay in your mailbox online, and your synced settings stay there for the next install. On this PC it removes:

  • The app itself, its Start menu and desktop shortcuts, and its Start with Windows entry.
  • Demo Mode’s sample data.
  • Unless you clear Also remove my local mailbox data and sign-in information: your sign-in, the copy of your mail, your settings and signatures on this PC (in every profile), the sign-in and debug logs, and temporary copies of attachments. Clear it to keep them for a later reinstall. Settings → Apps always removes them.

It doesn’t remove files you saved yourself (exported .pst and .mbox files, rules backups), other Windows users’ data on the same PC, or accounts you added to Windows itself (Settings → Accounts → Email & accounts).

Moving from classic Outlook

On a PC with classic Outlook, File → Open & Export → Import from Outlook brings across your signatures, Auto-Complete List and Quick Access Toolbar. It tells you what it found and asks first. Signatures you already have here are kept, and nothing in Outlook changes. Your rules and categories are in your mailbox, so they’re already here.

.pst files and backups

  • File → Open & Export → Open Outlook Data File shows a .pst in the folder pane without copying it into your mailbox, so an archive of any size can be read straight away. It’s read-only, and the file is never changed. Search covers subjects, senders and recipients, not message text. Right-click it for Open File Location, Data File Properties (where it is, its size and what’s in it) and Close Outlook Data File.
  • File → Open & Export → Import/Export copies the mail in a .pst into your mailbox. It needs changes allowed. Large files take a while, as Microsoft limits the rate.
  • File → Open & Export → Export to .pst saves a copy of a mailbox or folder. It works on a read-only mailbox too.
  • Right-click a folder for Export to .mbox: its messages in one .mbox file, which Thunderbird, Apple Mail and archive tools open. If it has subfolders, you’re asked whether to include them; each then becomes its own .mbox file, in folders that mirror yours. Right-click the mailbox itself to export everything. Save Folder As saves the messages as separate .eml files instead. Both work on a read-only mailbox and need to be online.
  • Only mail is opened, imported and exported, not calendars, contacts or tasks.

Appearance

View → Dark Mode switches between light and dark. File → Account → InCloseMail Theme has High Contrast and holiday themes. Ctrl+mouse wheel zooms the whole window and Ctrl+0 resets it. The slider on the status bar zooms only the message.

The arrow beside the buttons at the top left customizes the Quick Access Toolbar. Choose More Commands for any ribbon command.

When the Holiday theme changes

Choose a single holiday theme to keep it all year. Choose Holiday or Holiday (Dark) instead and InCloseMail follows the calendar: in the days before each holiday it switches to that holiday’s colors, keeps them through the day itself, and then goes back to the usual look. It changes at midnight, by your PC’s clock.
