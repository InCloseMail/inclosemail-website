What these numbers count
  • Installs come from the app's anonymous daily report (from 26.11.1002 on): one per Windows user on a PC, your own test copies included. Older versions don't report.
  • "New installs" are installs whose first report was their first ever launch. Until the app release after 26.11.1002, an older install that updated is counted as new too.
  • Downloads are GitHub's counts for each release's InCloseMail.msi: the website's Download button, the app's updater and your own installs. They can't tell people apart.
